PocketDeadlock сосредоточен на готовых VPK-модах через нативное приложение Windows. У Deadlock Mod Manager шире платформа и набор инструментов. Поиск, загрузки, порядок модов, профили и обновления есть у обоих проектов.

## Наши отличия

- **Нативный WPF-интерфейс для Windows.** Это выбор платформы. Он сам по себе не доказывает меньший расход памяти или более быстрый запуск.
- **Три источника в одном локальном индексе.** Повторный поиск использует сохраненные записи, пока каталоги обновляются. Полнота зависит от источников; часть модов сообществ требует ручного импорта.
- **Набор помещается в ключ.** Для расшифровки `PD1` не нужно обращаться к серверу хранения профилей. Интернет нужен для скачивания самих модов. Локальные VPK в ключ не включаются.
- **Выбор отделен от применения.** Есть видимые непримененные изменения, резервные копии конфигурации и откат сохраненных версий модов. Это наши документированные возможности, а не утверждение об отсутствии защиты у конкурента.

Наш вариант подходит для сосредоточенного Windows-сценария. Другой проект предлагает больше платформ и дополнительных инструментов. Полное равенство функций не входит в текущий объем PocketDeadlock.

## Что с Kaspersky

Поводом для проекта стало срабатывание антивируса в прежнем сценарии. Это не доказывает вредоносность какой-либо программы и не гарантирует, что другая реализация всегда избежит обнаружения.

В проверке 0.6.6 на одном компьютере без активных исключений новых срабатываний при сканировании, запуске и обновлении не наблюдалось. Ранее диагностический процесс самого PocketDeadlock вызывал обнаружение. [Подробный отчет](../Проверка.md) содержит точный пакет и границы результата. Текущий прием конкурента антивирусом не проверялся.
